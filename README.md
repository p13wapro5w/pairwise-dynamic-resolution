# pairwise-dynamic-resolution

战斗一激烈画面就变糊，动态分辨率按 GPU 时间调整，缩放后 UI 也跟着一起缩；只改了渲染目标尺寸，相机投影矩阵没更新，画面被拉伸；UI 和 3D 共用一张渲染目标，字体被重采样成毛边；缩放决策用的是上一帧的 GPU 时间，负载突变时反应慢半拍；每次调整跨 20% 台阶，画面像在切档；帧时间在阈值附近抖动，分辨率来回横跳；放大回原生分辨率时历史缓冲没有重投影，TAA 拖出一圈残影；后处理的 bloom 按固定尺寸分配，缩放后光晕比例不对；锐化强度写死，低分辨率下边缘过锐；分屏双相机共用一套缩放因子，一边清晰一边糊。render/dynamic_resolution.py 是核心，tests/test_dynamic_resolution.py 15个红。要修的是：同步更新投影；UI 独立目标；平滑帧时间；小步进；滞回区间；历史重投影；TAA 按比例；后处理链按比例；锐化补偿；按相机独立。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
